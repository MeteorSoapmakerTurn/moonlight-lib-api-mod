# Moonlight Lib — Shared Mod Library

[![Download Latest](https://img.shields.io/github/v/release/MeteorSoapmakerTurn/moonlight-lib-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/MeteorSoapmakerTurn/moonlight-lib-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A shared library providing common utilities for mods by MehVahdJukaar, including Supplementaries.

![Moonlight Lib — Shared Mod Library Preview](https://cdn.modrinth.com/data/twkfQtEc/icon.png)

## Features

- Dynamic holder registry for extensible mod content
- Multiloader compatibility helpers for Forge and Fabric
- Custom renderer hooks for block and entity display
- Sound engine utilities for ambient sound integration
- Required by Supplementaries, Amendments, and more

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
